## UpgradeLink を選ぶ理由？
個人開発者の小規模ツールから企業級の複雑なアプリケーションまで、一括で全端アップグレード機能に接続でき、ゼロからサービスを構築する必要はありません：
- 🚀 **すぐに使える**：アップグレードロジックを深く研究する必要なく、SDKの導入は10分で完了
- 🌍 **全端対応**：Windows/Linux/Mac/Android/Tauri/Electronなど全シーンをサポート
- 💰 **コスト大幅削減**：サーバー構築、クロスプラットフォーム適応の開発投入を削減
- 🔒 **企業級の信頼性**：セキュリティ保護+柔軟な戦略、グレースケールリリース/定向アップグレードをサポート
- 📦 **柔軟なストレージサポート**：S3プロトコルオブジェクトストレージをサポート、CDNダウンロードアドレスをカスタマイズ可能


## コア機能：全シーンアップグレードソリューション
### 1. マルチプラットフォーム/フレームワーク専用アップグレード
| サポートタイプ     | コア機能                          | 適用シーン                  |
|------------------|-----------------------------------|---------------------------|
| Windows アプリ    | 専用アップグレード戦略管理          | PCデスクトップアプリ        |
| Linux アプリ      | サーバー/デスクトップアップグレード要件に適応 | サーバーツール、Linuxデスクトップアプリ |
| Mac アプリ        | アップルエコシステムに準拠したアップグレードフロー | Macデスクトップアプリ       |
| Android アプリ     | 差分アップグレード（インクリメンタルアップデート）をサポート | モバイルAPP                   |
| Tauri アプリ      | 公式コンポーネントインターフェースと互換性があり、シームレスなアップグレード | Tauriクロスプラットフォームアプリ             |
| Electron アプリ    | 公式アップグレードインターフェースと互換性があり、ゼロ改造で導入 | Electronクロスプラットフォームアプリ      |

### 2. 柔軟なリソースアップグレード
| アップグレードタイプ | 機能説明                          | 適用シーン                  |
|------------|-----------------------------------|---------------------------|
| 設定アップグレード   | カスタムJSON設定、オンライン動的更新をサポート | 動的にパラメータを調整する必要があるアプリ    |
| ファイルアップグレード | 任意のファイルをアップロード、リソースの追加/置換をサポート | 素材、プラグインを更新する必要があるアプリ    |
| URLアップグレード    | カスタムダウンロードリンク、ファイルストレージを自ら管理 | 既にクラウドストレージサービスを使用しているアプリ      |

### 3. 柔軟なストレージと配布
- 📦 **S3プロトコルサポート**：すべてのアプリケーションバージョンファイルはS3プロトコルに対応するオブジェクトストレージサービスに保存できます
- 🌐 **カスタムCDN**：カスタムCDNダウンロードアドレスの設定をサポートし、グローバルユーザーのダウンロード体験を最適化

## マイルストーン
### v3.0.0 (2026-01-26)
- ⚡ **二次開発サポート**：コア機能として二次開発サポート機能を追加し、関連ドキュメントを継続的に更新
- 🔧 **バックエンド再構築**：adminバックエンドシステムを全面的に再構築、複数サービスを1つに統合、7つのプロジェクトモジュールを3つに精簡
- 📈 **維持コスト削減**：不要なバックエンドモジュールを整理し、プロジェクト維持コストを大幅に削減

### v2.0.0 (2025-09-24)
- 🚀 **公式オープンソース**：プロジェクトが正式にオープンソース化
- ⚡ **高速トラフィックパッケージ**：高速トラフィックパッケージをサポートし、企業ユーザーのアプリケーションアップグレードを支援
- 📦 **マルチプラットフォームサポート**：Windows/Linux/Macアプリケーションアップグレードモジュールをサポート
- 🔧 **自動デプロイ**：Tauri/Electron Github Actionモジュールを追加し、自動デプロイとアップグレードをサポート

### v1.x シリーズ
- 🌱 **基本機能構築**：v1.4.0からv1.9.0まで、コア機能を段階的に実装
- 📱 **プラットフォーム拡張**：Androidアプリケーションアップグレード、設定アップグレードなどの機能をサポート
- 📊 **データ統計**：アプリケーショントラフィック統計、収入モジュールなどを追加
- 🌐 **グローバルアクセス**：アプリケーションダウンロードと配布ページがグローバルアクセスをサポート
