## ✨ چرا UpgradeLink را انتخاب کنیم؟

چه یک ابزار کوچک توسط توسعه‌دهندگان فردی باشد و چه یک اپلیکیشن پیچیده شرکتی، می‌توانید به صورت آنی قابلیت‌های ارتقای کامل را بدون ساخت سرویس‌ها از ابتدا ادغام کنید:

- 🚀 **آماده استفاده**: نیازی به غوطه‌ور شدن در منطق ارتقا نیست — ادغام SDK فقط ۱۰ دقیقه طول می‌کشد
- 🌍 **پوشش چند‌پلتفرمی**: از Windows/Linux/Mac/Android/Tauri/Electron و سایر سناریوهای کامل پشتیبانی می‌کند
- 💰 **کاهش هزینه**: سرمایه‌گذاری تحقیق و توسعه در راه‌اندازی سرور و سازگاری چند‌پلتفرمی را حذف می‌کند
- 🔒 **قابلیت اطمینان شرکتی**: محافظت امنیتی + استراتژی‌های انعطاف‌پذیر، پشتیبانی از انتشار کاناری/ارتقای هدفمند
- 📦 **پشتیبانی از ذخیره‌سازی انعطاف‌پذیر**: از ذخیره‌سازی اشیاء با پروتکل S3 پشتیبانی می‌کند، آدرس دانلود CDN قابل سفارش است

## 🔐 احراز هویت نسخه شرکتی

### دریافت اعتبارنامه دسترسی شرکتی

۱. **دسترسی به کنسول شرکتی**: https://www.toolsetlink.com  
۲. **ثبت‌نام حساب شرکتی** و تکمیل تأیید  
۳. **ایجاد پروژه شرکتی** برای دریافت اعتبارنامه‌های API

### روش‌های احراز هویت

- **احراز هویت با کلید API**: افزودن `Authorization: Bearer <your-api-key>` در هدرهای درخواست
- **احراز هویت OAuth 2.0**: پشتیبانی از جریان استاندارد OAuth 2.0 (اختیاری)

### روند استفاده

**ثبت‌نام حساب شرکتی** → **ایجاد پروژه** → **دریافت اعتبارنامه** → **ادغام SDK** → **انتشار اپلیکیشن**

[همین حالا ثبت‌نام کنید](https://www.toolsetlink.com) | [مشاهده مستندات](https://www.toolsetlink.com/fa/upgrade/deploy/quick-start-docker.html)

## 💎 مزایای رایگان نسخه شرکتی

خدمات سطح شرکتی را به صورت رایگان، بدون نیاز به استقرار خودکار، ارائه می‌دهیم، شامل:

- ✅ **سهمیه رایگان**: سهمیه ماهانه کافی از ارتقاهای رایگان
- ✅ **دسترسی به تمام ویژگی‌ها**: از تمام ویژگی‌های پریمیوم بدون محدودیت لذت ببرید
- ✅ **پشتیبانی فنی**: تیم پشتیبانی فنی حرفه‌ای آنلاین
- ✅ **CDN جهانی**: شبکه شتاب‌دهی جهانی که دانلود سریع را برای کاربران تضمین می‌کند
- ✅ **امنیت**: محافظت امنیتی سطح شرکتی با ذخیره‌سازی داده‌های رمزنگاری شده

> 💡 **توجه**: برای اکثریت قریب به اتفاق توسعه‌دهندگان و کسب‌وکارهای کوچک و متوسط، سهمیه رایگان به طور کامل نیازهای استفاده روزمره را برآورده می‌کند.  
> برای سهمیه‌های بالاتر یا خدمات انحصاری، لطفاً با تیم فروش ما تماس بگیرید.

**شروع کنید**: [ثبت‌نام حساب شرکتی](https://www.toolsetlink.com) | [مشاهده جزئیات قیمت‌گذاری](https://www.toolsetlink.com/fa/upgrade/company/company.html)

## 🎯 ویژگی‌های اصلی: راه‌حل‌های ارتقا برای تمام سناریوها

### ۱. ارتقاهای مخصوص پلتفرم/چارچوب

| نوع پشتیبانی شده | قابلیت‌های اصلی | موارد استفاده |
|-----------------|----------------|--------------|
| اپلیکیشن‌های Windows | مدیریت استراتژی ارتقای اختصاصی | اپلیکیشن‌های دسکتاپ PC |
| اپلیکیشن‌های Linux | سازگاری با نیازهای ارتقای سرور/دسکتاپ | ابزارهای سرور، اپلیکیشن‌های دسکتاپ Linux |
| اپلیکیشن‌های Mac | روند ارتقای سازگار با اکوسیستم Apple | اپلیکیشن‌های دسکتاپ Mac |
| اپلیکیشن‌های Android | پشتیبانی از بروزرسانی‌های دلتا (بروزرسانی‌های افزایشی) | اپلیکیشن‌های موبایل |
| اپلیکیشن‌های Tauri | سازگاری با APIهای قطعه‌های رسمی برای ارتقاهای بدون وقفه | اپلیکیشن‌های چند‌پلتفرمی Tauri |
| اپلیکیشن‌های Electron | سازگاری با APIهای ارتقای رسمی، ادغام بدون تغییر | اپلیکیشن‌های چند‌پلتفرمی Electron |

### ۲. ارتقاهای منابع انعطاف‌پذیر

| نوع ارتقا | توضیح ویژگی | موارد استفاده |
|-----------|-------------|--------------|
| ارتقای پیکربندی | پیکربندی JSON سفارشی با بروزرسانی‌های پویای آنلاین | اپلیکیشن‌هایی که نیاز به تنظیمات پویای پارامترها دارند |
| ارتقای فایل | بارگذاری هر فایلی برای پشتیبانی از تکمیل/جایگزینی منابع | اپلیکیشن‌هایی که نیاز به بروزرسانی مواد یا پلاگین‌ها دارند |
| ارتقای URL | لینک‌های دانلود سفارشی با ذخیره‌سازی فایل خودمدار | اپلیکیشن‌هایی با سرویس‌های ذخیره‌سازی ابری موجود |

### ۳. ذخیره‌سازی و توزیع انعطاف‌پذیر

- 📦 **پشتیبانی از پروتکل S3**: تمام فایل‌های نسخه اپلیکیشن را می‌توان در سرویس‌های ذخیره‌سازی اشیاء سازگار با S3 ذخیره کرد
- 🌐 **CDN قابل سفارش**: از پیکربندی آدرس‌های دانلود CDN سفارشی برای بهینه‌سازی تجربه دانلود کاربران جهانی پشتیبانی می‌کند

## 📝 نقاط عطف

### v3.0.0 (2026-01-26)

- ⚡ **پشتیبانی از توسعه ثانویه**: ویژگی اصلی جدید پشتیبانی از توسعه ثانویه، با مستندات تکمیلی که به طور مداوم به‌روزرسانی می‌شود
- 🔧 **بازسازی بک‌اند**: بازسازی جامع سیستم بک‌اند admin، ادغام چندین سرویس در ۱ سرویس، کاهش ۷ ماژول پروژه به ۳

- 🚀 **منبع باز رسمی**: انتشار رسمی پروژه به عنوان منبع باز
- ⚡ **بسته ترافیک پرسرعت**: پشتیبانی از بسته ترافیک پرسرعت، کمک به کاربران شرکتی برای ارتقای سریع اپلیکیشن‌ها
- 📦 **پشتیبانی چند‌پلتفرمی**: پشتیبانی از ماژول‌های ارتقای اپلیکیشن‌های Windows/Linux/Mac
- 🔧 **استقرار خودکار**: افزودن ماژول‌های Tauri/Electron Github Action، پشتیبانی از استقرار و ارتقای خودکار

### سری v1.x

- 🌱 **ساخت قابلیت‌های پایه**: از v1.0.0 تا v1.9.0، اجرای تدریجی ویژگی‌های اصلی
- 📱 **گسترش پلتفرم**: پشتیبانی از ارتقای اپلیکیشن‌های Android، ارتقای پیکربندی و سایر ویژگی‌ها
- 📊 **آمار داده‌ها**: افزودن آمار ترافیک اپلیکیشن، ماژول درآمد و غیره
- 🌐 **دسترسی جهانی**: صفحات دانلود و توزیع اپلیکیشن از دسترسی جهانی پشتیبانی می‌کنند
